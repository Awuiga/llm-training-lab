# Откуда взялись результаты

Метрики перенесены из сохранённой истории эксперимента и проверены по локальным checkpoints 8 ноября 2026 года. Это восстановленная выборка, а не полный журнал каждого интервала.

- `char_v1.csv`: доступные строки вывода пользователя для шагов 100, 9950 и 10000. Лучший loss на 9350 округлён в консоли; точное значение `1.3982875347137451` подтверждено checkpoint.
- `bpe_v2.csv`: validation на 100–5000 взят из сохранённого графика в ответе на приложенный лог. Эти промежуточные значения округлены до четырёх знаков и являются вторичным источником. На 100 есть прямая строка пользователя: train `5.995696067810059`, val `6.008559226989746`.
- На 4750 точное best val `3.8321166038513184` подтверждено checkpoint. На 5000 train `3.8036141`, val `3.8669281` перенесены из данных пользователя при подготовке публикации; checkpoint не хранит последние train/val.
- Полный исходный вложенный лог BPE на 5000 шагов недоступен в экспорте истории. Пропущенные измерения не восстановлены искусственно. Пустая ячейка CSV означает отсутствие данных. Отдельные ранние пробные запуски на 50 шагов не объединены с основным экспериментом.
- Точки на графиках — только доступные наблюдения. Для редких измерений train показаны отдельные точки; линии validation соединяют доступные точки без сглаживания. Между 100 и 9950 у char нет восстановленной кривой.

Оба loss — средняя cross-entropy на 20 случайных батчах, batch size 4. Это не оценка на всём корпусе и не результат независимого теста. Исторические seed обучения и состояние генератора случайных чисел не сохранены.

`checkpoints.json` содержит только числовые настройки и результаты, извлечённые через `torch.load(..., weights_only=True)`. Веса и состояние AdamW не публикуются. `data_fingerprints.json` позволяет сравнить повторно подготовленные данные с локальными файлами эксперимента.

Примеры в README скопированы из реального вывода пользователя без исправления ошибок. Исторический seed генерации неизвестен; дословное повторение не гарантируется.
