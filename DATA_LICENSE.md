# Данные и токенизатор

Источник: Ilya Koziev (inkoziev), **ru-stories: A Dataset of Five-Sentence Russian Short Stories for Language Model Evaluation**, 2025, Hugging Face.

- [Карточка и сведения о лицензии](https://huggingface.co/datasets/inkoziev/ru_stories/blob/main/README.md).
- [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), [полный текст](https://creativecommons.org/licenses/by-nc/4.0/legalcode).
- Ревизия данных для повторного скачивания: `26173ec5e84f118a0294f6cf8936dfef1f39033d`. Исторический запуск не сохранял ревизию; совпадение следует проверять по хешам локальных файлов.

Использован только исходный split `train`. Пять предложений каждой истории соединены пробелами, истории разделены пустой строкой. Для v2 истории перемешаны с seed 42 и разделены 90/10; ByteLevel BPE обучен только на полученной обучающей части.

`data/tokenizer_v2.json` — полученный в этом эксперименте словарь и правила BPE, а не копия корпуса. Для его распространения здесь консервативно сохранены атрибуция и условия CC BY-NC 4.0: некоммерческое использование, указание автора исходного материала, ссылки на источник и лицензию, обозначение изменений.
